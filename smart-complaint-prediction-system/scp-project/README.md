# Smart Complaint Prediction System

**Final Year Project - Predictive Maintenance for Hostel Complaints**

## Quick Start

1. Open `index.html` in your browser
2. Login with demo account:
   - Admin: `admin@scp.com` / `Admin@123`
   - Student: `student@scp.com` / `Student@123`

## Features

✅ Predictive risk scoring  
✅ Auto-preventive maintenance tickets  
✅ Student complaint portal  
✅ Admin dashboard with risk heatmaps  
✅ Model accuracy tracking  
✅ Real-time complaint management  

## Tech Stack

- HTML5, CSS3, JavaScript
- Responsive design
- Browser-based storage (no backend)

## Deployment

Ready to deploy on:
- Netlify
- Vercel
- GitHub Pages
- Any static hosting
